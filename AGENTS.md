# Инструкции для агентов

Перед добавлением или изменением локализации MC прочитайте [руководство по локалям MC](docs/agents/localization-mc.md).
При написании, изменении и ревью C#-кода в этом репозитории, включая тесты, обязательно соблюдай [руководство по стилю Hypercube](docs/CODING_STYLE.md). Перед началом работы прочитай руководство, а при проверке изменений сверь с ним затронутый код.
